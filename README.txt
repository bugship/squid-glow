Glowing Octopus
===============

A small command-line "is the internet still glowing?" checker,
plus a deluxe Web 2.0 HTML dashboard (tables included free of charge).

I got tired of opening eight browser tabs to see if Digg, Twitter,
and my shared host were still alive. So I wrote a squid that pings
them for me.

CLI Usage
---------
    python glow.py
    python glow.py --plain

Edit sites.conf (Name|URL per line) to choose what to watch.

Dashboard
---------
Open web/index.html in a browser. It is mostly decorative.
Think of it as a mood board for uptime.

Requires
--------
* Python 2.5+ (2.6 recommended)
* A browser from this decade (or the previous one, if you must)
